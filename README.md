## Selected work

### Telegram Community Platform

A community management application with a React dashboard, a FastAPI backend, and an Aiogram Telegram bot.

- Student registration and community profiles
- Support tickets and administrator workflows
- Channel subscription checks, analytics, and audit logs

**Stack:** Python · FastAPI · React · TypeScript · SQLAlchemy · PostgreSQL / SQLite

[Repository — access required](https://github.com/bahodirboliqulov3/telegram-community-platform)

### AsilbekMath Test Bot

A Telegram testing platform for creating tests, checking answers, and reviewing student results.

- Question banks and answer-key submissions
- Test schedules, attempt limits, and randomized questions
- Excel imports and exports, result reports, and PDF certificates

**Stack:** Python · Aiogram · SQLAlchemy · OpenPyXL · ReportLab

[Repository — access required](https://github.com/bahodirboliqulov3/asilbekmath-test-bot)

### Sweet Greetings

A React project for personalized Uzbek greetings and celebration cards.

**Stack:** React · TypeScript · Vite · Tailwind CSS

[Repository — access required](https://github.com/bahodirboliqulov3/sweet-greetings)
